# MessageVault releases

This repository distributes MessageVault installers and release notes. Application source code is maintained separately.

Download the package for your operating system from [Releases](https://github.com/fadil-pezo/MessageVault-releases/releases). Updates are checked inside MessageVault; no GitHub account or personal access token is required.

Each installer has a detached `.sig` publisher signature. MessageVault verifies the publisher signature and the release SHA-256 before installation. Archives, profiles and publisher private keys are not distributed here.
